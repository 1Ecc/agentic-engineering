## 目录地图

- `spec/`:SDD/TDD 规格产物——需求索引看 `spec/INDEX.md`,项目地图看 `spec/README.md`。
- `src/`:业务代码、程序入口与脚本;按职责组织,不要求与 `spec/needs/` 一一对应。
- `tests/`:测试代码与测试样例。
- `docs/`:原始文档资料、说明与长期维护的知识。
- `data/`:各类数据与运行结果,内部按项目需要渐进组织。
- `dist/`:构建产物;有构建时由工具生成。
