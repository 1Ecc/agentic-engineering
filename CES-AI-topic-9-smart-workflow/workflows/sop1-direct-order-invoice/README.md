# SOP1 Workflow：直客订单查询及发票处理

该目录用于承载 SOP1 的可执行配置、规则、邮件模板和测试样例。

当前先沉淀 workflow 与规则草案，后续实现连接器时保持字段名不变，减少前后端和规则层的联动成本。

## 输入

- `work_order_no`：工单号。

## 输出

- `result_rows`：查询结果行，支持多个 BTCP 结果。
- `matched_rule`：命中的异常规则编号。
- `email_draft`：邮件草稿；未命中异常规则时为空。
- `run_log`：执行步骤、截图、错误信息。

## 执行策略

SOP1 先采用固定编排，不开放拖拽配置。每个步骤内部可以逐步抽象为平台化模块。
