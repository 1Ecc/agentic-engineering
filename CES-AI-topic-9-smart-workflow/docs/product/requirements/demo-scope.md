# Demo 边界 PRD

## 1. 真实链路原则

阶段二 demo 不通过 mock/fallback 伪造成功。

必须真实的链路：

- LLM provider 调用。
- MCP 浏览器录制。
- Network 请求和 response body 采集。
- ApiCaptureSpec 生成。
- NodeDefinition 转换和校验。
- 草稿节点试调用。
- 节点市场试运行。
- workflow runner 执行。
- 登录态复用。

---

## 2. 失败策略

| 失败点 | 策略 |
|---|---|
| LLM_PROVIDER 未配置 | 明确配置错误 |
| provider key 缺失 | 明确缺少对应 key |
| MCP 不可用 | 录制启动失败 |
| 抓包为空 | 提示未捕获业务 API 请求 |
| 业务请求过滤后为空 | 提示没有可用于生成节点的业务请求 |
| response body 缺失 | 不生成高置信运行映射 |
| LLM 输出不合规 | 展示 schema 校验错误 |
| 未知节点类型 | workflow 校验失败或运行失败 |
| 鉴权失效 | `AUTH_REQUIRED` 并拉起登录 |
| 输出映射失败 | `DATA_NOT_FOUND` |

---

## 3. 演示路径

推荐演示：

1. 打开“我的流程”，展示已保存 SOP1 或直客订单工作流。
2. 运行一个真实 workflow，证明阶段一链路可信。
3. 打开“节点市场”，展示内置能力、平台分组和我的录制。
4. 打开“录制接口”，录制一个真实平台操作。
5. 完成录制，生成节点草稿并试调用。
6. 注册节点到我的录制，按需同步到市场。
7. 打开“新建工作流”，用自然语言生成 workflow。
8. 在卡片视图中校验和试运行。
9. 保存并使用。

---

## 4. 风险与预案

| 风险 | 等级 | 预案 |
|---|---|---|
| 演示现场网络或平台不稳定 | 高 | 提前保存登录态，准备可复现 recording 和运行记录用于解释断点 |
| LLM 输出不稳定 | 中 | 强 schema 校验，展示失败原因，不伪造成功 |
| MCP 抓包失败 | 中 | 明确显示 MCP/页面/请求数问题 |
| 业务登录态失效 | 高 | 复用登录浏览器，现场可重新保存 |
| 评委追问是否任意流程可跑 | 高 | 明确只跑已注册节点和真实 handler |
| 评委追问后续平台能力 | 中 | 说明二期评估成熟开源工作流平台底座 |

## 5. 当前验收清单

- [ ] 工作流列表展示真实可运行 workflow。

- [ ] 节点市场能展示平台分组和我的录制。
- [ ] 录制接口能完成真实 MCP 录制。
- [ ] 录制节点能草稿试调用。
- [ ] 鉴权失效能拉起登录流程。
- [ ] 真实依赖缺失时明确失败。

---

## 6. 明确非目标

- 不承诺生产级稳定性。
- 不承诺任意网站任意接口都可自动生成节点。
- 不承诺完整 workflow 平台能力。
- 不承诺复杂权限、审计和协作。
- 不承诺无需人工确认的节点自动发布。
