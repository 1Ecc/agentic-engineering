# Skills Hub PRD

## 1. 定位

Skills Hub 是与“节点市场”平级的展示级 demo 板块，用于表达平台未来可以沉淀业务 AI 技能的方向。

节点市场偏“接口/工具节点”，Skills Hub 偏“面向业务场景的 AI 能力单元”。

---

## 2. 当前范围

- 左侧导航新增 “Skills Hub”。
- 路由为 `#/skills`。
- 页面展示精选技能卡片和概览指标。
- 视觉风格与当前平台一致。

当前不做：

- 搜索
- 安装
- 配置
- 权限
- 执行
- 与 workflow 生成联动
- 后端 API

---

## 3. 展示内容

页面应表达：

- Skills Hub 是平台级能力入口。
- Skill 是比单个接口节点更靠近业务场景的 AI 能力。
- 当前只是 demo preview，不承诺完整技能市场。

示例技能：

- 表单识别
- 数据洞察
- 邮件生成
- 知识检索

---

## 4. 后续演进

如果后续要产品化，需要另起专题设计：

- Skill 定义 schema。
- Skill 与节点的关系。
- Skill 是否可被 workflow 引用。
- Skill 安装、配置、权限和版本。
- Skill Hub 与节点市场是否合并为统一能力市场。

---

## 5. 验收标准

- 左侧导航展示 Skills Hub。
- 与节点市场平级。
- 访问 `#/skills` 能看到展示页。
- 页面不引入后端依赖，不影响其他流程。
