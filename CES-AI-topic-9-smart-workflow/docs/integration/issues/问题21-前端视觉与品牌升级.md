# 问题 21：前端视觉与品牌升级

## 问题描述

当前阶段二平台原型在视觉表达、信息排版和品牌定位上还停留在 Demo 阶段，与"AI 驱动的企业 SOP 自动化平台"的产品定位明显不匹配。需要做一次面向产品形态的前端视觉与品牌升级，覆盖运行页、节点市场、品牌 4 个层面：

1. 「我的流程 / 直客订单两阶段处理 · 运行界面」（`WorkflowRun.vue`）
   1. 顶部"运行工作流" → "总进度 / 模块完成 / 结果 / 节点输出"四个 metric panel → 一直到下方"节点流程"，整体排版与视觉呈现粗糙，metric panel 没有形成有效的运行态概览。
   2. "节点流程"虽然包装成了画布（`.workflow-graph`），但单 stage 内多节点纵向堆叠、stage 之间的连接线和卡片会出现视觉重叠，画布感不强。
   3. "结构化结果 / 运行日志 / 历史运行"在未运行前是大段空状态，排版稀疏、缺乏占位引导，运行后日志列表也是裸 `ul`。

2. 节点市场（`NodeMarket.vue`）
   1. 内置通用能力（7）卡片样式简陋，icon fallback 是字符 "N"，整体观感像未完成原型。
   2. 「已接入平台（3 个平台 · 3 个节点 · 6 个接口）」呈现：
      - 平台列表（`.platform-list`/`.platform-group`）样式简陋；
      - 默认状态没有自动选中第一个平台，导致下方一直是"选择平台查看节点"的空态；
      - 期望默认展开"已有接入的平台"，点击平台后切换二级节点视图。
   3. "我的录制"区的节点卡片（`.node-card.recorded`）与上方内置卡片样式割裂，footer 信息密度低，"同步到节点市场"按钮也缺乏视觉权重。

3. 品牌
   - 侧边栏当前 brand 区显示「智能工作台 / 九号课题 · 阶段二」。
   - 期望整体改名为「连连看」，副标题改为「AI 驱动的企业 SOP 自动化平台」，且 brand mark "W" 也需要同步替换。
   - 浏览器 title（`apps/web/index.html`）也需要同步更新。

## 当前态

- 视觉层：`apps/web/src/styles.css` 中 `.command-band` / `.overview-grid` / `.metric-panel` / `.flow-panel` / `.content-grid` / `.market-group` / `.node-card` 等区块均为早期 Demo 风格，缺乏统一的视觉语言。
- 信息层：
  - 运行页 `metric-panel` 只展示数值，没有承担"运行态总览"的角色（运行状态、耗时、当前阶段、错误数等都散落在右上角 `.run-badge`）。
  - 节点市场顶部"内置通用能力" / "已接入平台" / "我的录制"三段平铺，没有体现"先平台、再节点"的二级关系。
- 品牌层：侧边栏与 `index.html` 仍保留旧名称，没有体现新的产品定位。

## 期望态（需要跟用户沟通确认）

已确认（2026-05-16）：

1. 品牌
   - 平台正式名称改为「连连看」。
   - 副标题改为「AI 驱动的企业 SOP 自动化平台」。
   - 侧边栏 brand mark：内联 SVG，画"两个互联节点（两个圆点 + 中间连接线）"，呼应「节点编排 / 节点互联」语义。
   - 浏览器 title 同步改成「连连看 · AI 驱动的企业 SOP 自动化平台」。

2. 运行页（`WorkflowRun.vue`）
   - 顶部"运行工作流" + "总进度 / 模块完成 / 结果 / 节点输出"四个 metric 卡片整体重排，形成统一的"运行驾驶舱"区，使用 sticky/分组样式与现有色板。
   - 节点流程画布：
     - 修复 stage 间 `::after` 连接线压到下一 stage 卡片的问题（用独立的箭头列承载连接线，stage 内 padding 与 gap 调整）。
     - 修复同一 stage 内多个节点视觉挤在一起的问题（增大 `.stage-nodes` 间距、给每个节点设最小高度与分隔）。
   - 结构化结果 / 运行日志 / 历史运行：未运行前提供更"产品化"的空态（图标 + 引导文案 + 提示该区域的用途），运行后日志保留时间轴排版。

3. 节点市场（`NodeMarket.vue`）
   - 内置通用能力卡片：去掉字符 "N" 的硬编码 fallback；icon 区使用 category 颜色 + 首字母 / emoji；统一卡片圆角、阴影、悬停效果。
   - 已接入平台：保留"平台卡片"，新增"点击平台 → 右侧抽屉/侧栏展示该平台节点"的交互（右侧抽屉与已有 `.node-detail` 共享视觉规范），默认不强制选中平台，但平台卡 hover 给出 affordance。
   - 我的录制：卡片视觉与上方对齐，"同步到节点市场"按钮做成 chip / pill 样式，已同步时显示 ✓ 状态。

4. 视觉基调
   - 沿用现有色板（浅色内容区 + 深色侧边栏 + 蓝/绿强调色）做精修，不改色板，不引入新的视觉框架。

## 分析与解决

已实施（2026-05-16）：

1. 品牌
   - `apps/web/index.html` title → `连连看 · AI 驱动的企业 SOP 自动化平台`。
   - `apps/web/src/App.vue` 侧边栏 brand 区：名称改「连连看」、副标题改「AI 驱动的企业 SOP 自动化平台」、brand mark 改成内联 SVG（两个圆点 + 中间连接线），并补充 `.brand-mark svg { 24px }` 与轻量阴影。

2. 运行页（`apps/web/src/styles.css`）
   - `.command-band` 升级：圆角 14px、双层渐变背景、加重阴影，让"运行工作流"区像驾驶舱头部。
   - `.metric-panel` 升级：12px 圆角、左侧 4px 渐变色条按顺序使用 蓝/绿/橙/紫 区分四张卡（总进度 / 模块完成 / 结果 / 邮件/节点输出）；hover 时上浮 + 阴影；标题加粗、数值字号 30px。
   - `.workflow-graph` 修复"节点重叠"：
     - 画布背景改成"浅网格点阵"，强化画布感。
     - stage 间 `gap: 56px`，原 `::after` 18×2 短线 改成"短线 + 三角箭头"独立连接层（`right: -42px/-46px`），同时给箭头 `pointer-events: none`，避免被点击；箭头与线条都收敛在 stage 间留白内，不再压到下一卡片。
     - 同 stage 内 `.stage-nodes gap` 由 12px → 16px，卡片增加白色背景与阴影，hover 上浮；`.stage-label` 改成胶囊标签，与节点卡视觉分离。
   - 结构化结果 / 运行日志 / 历史运行：
     - `.empty-state` 改成虚线 + 圆点纹理 + 顶部圆形装饰的产品化空态。
     - `.log-panel ul` 改成竖向时间轴（左侧 2px 浅色轴线，每条日志前一个圆点）。

3. 节点市场（`apps/web/src/pages/NodeMarket.vue` + `styles.css`）
   - 去掉字符 "N"/"P"/"R" 硬编码 fallback：新增 `nodeIconChar(node)` 按平台 emoji / 分类 emoji 选择；新增 `categoryAccent(category)` 让卡片 icon 容器按"内置=蓝 / connector=绿 / recorded=紫"上色（`color + '22'` 浅背景 + 实色 icon）。
   - 「已接入平台」改为 3 列响应式平台卡片（`.platform-card`），每张卡片包含 logo 圆角、平台名、节点/接口数、左侧色条 + 「查看节点 →」CTA。点击平台后由右侧 `.platform-drawer` 抽屉承载该平台节点；点击节点时由原 `.node-detail` 抽屉承载详情，二者切换互斥；`closeDrawer()` 一并清空两种选中。
   - 「我的录制」卡片：`.node-meta` 用 chip 展示输入/输出数量与创建人；「同步到节点市场」按钮升级成 `.sync-pill`（已同步显示绿色 ✓ pill，未同步显示蓝色 pill）。
   - 三个 `.market-group` 顶部统一 `.market-group-head`（标题 + 描述 + 右上角数量徽标）；统计文案仍为「3 个平台 · 3 个节点 · 6 个接口」（与问题 15 一致）。

4. 验证
   - `npm run build`（vue-tsc + vite build）通过，无类型错误。

未做（避免越界）：

- 未改色板、未引入新的视觉框架；未改动后端数据模型与节点市场可见性接口；未改动 sop1 直客订单的业务卡片 `StepCard`。

待确认的关键点（保留以备未来回顾）：

1. 品牌：
   - 「连连看」是否就是最终对外名称（用户验收时是否会再调整）？
   - brand mark 是用文字 "连" 还是单独的几何 logo（如果要 logo 我会用 SVG 内联，避免新增静态资源依赖）？

2. 运行页"节点流程"重叠：
   - 重叠是指 stage 间连接线 `::after` 与下一 stage 卡片在某些宽度下重合，还是同一 stage 内多个节点之间的视觉重叠？
   - 是否接受我把画布从横向滚动改为响应式自适应（窄屏时上下排）？

3. 节点市场默认呈现：
   - 默认进入页面时是"自动选中第一个平台"还是"折叠展示所有平台 + 每个平台下挂节点"？我倾向前者（最小改动 + 引导清晰）。

4. 整体视觉基调：
   - 是否保留当前浅色背景 + 深色侧边栏？
   - 还是希望切换成更现代的 dark glass / 玻璃拟态风格？建议沿用当前色板做精修，避免大规模重构。
