# Integration 联调优化入口

> 本目录是后续联调、优化、debug、体验调整和架构调整的过程信源。  
> 历史联调主题已迁入 `docs/integration/issues/`，后续新增主题统一从这里维护。

## 使用规则

1. 后续新增联调/优化主题放在 `docs/integration/issues/`。
2. 历史问题文档已迁入 `docs/integration/issues/`。
3. 联调文档是协作缓冲区，记录问题、当前态、期望态、分析、to-issues、bug、验收状态。
4. 用户尚未验证前，不把临时判断直接沉淀到产品 PRD 或技术方案。
5. 用户验收或阶段性稳定后，再沉淀到：
   - `docs/product/`
   - `docs/architecture/`
   - `docs/decisions/`
