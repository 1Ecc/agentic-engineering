# ADR-006：一期证明核心主张，二期评估成熟平台底座

## 状态

建议采纳，待二期 PoC 验证。

## 背景

当前 demo 证明的差异化价值是企业系统操作录制成工具，以及 AI 基于工具自动编排业务流程。完整工作流平台能力如画布、调试、版本、权限、发布和插件生态成本很高，不应全部从零自研。

## 决策

一期继续用自研 demo 证明核心主张；二期评估 FastGPT 等成熟开源 AI 工作流平台作为底座，把研发重点放在企业工具生产层和 AI 工作流编排层。

## PoC 建议

1. 本地部署候选平台。
2. 用 HTTP 节点调用当前录制节点 API。
3. 包装录制节点服务为 MCP Server。
4. 手工搭建 SOP1 最小 workflow。
5. 分析 workflow JSON。
6. 尝试让 LLM 生成平台 workflow JSON。
