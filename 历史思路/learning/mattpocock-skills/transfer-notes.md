# Matt Pocock Skills 可迁移笔记

学习案例后，在这里记录可复用想法。

## 候选迁移点

- skills 保持小而可组合，不独占整个流程。
- 用 `CONTEXT.md` 维护领域词汇。
- ADR 只记录难以逆转、非显然、来自真实 trade-off 的决策。
- 将工作拆成纵向 tracer-bullet 切片。
- 通过公共接口测试行为，而不是测试实现细节。

## 潜在冲突

- PRD / issue 概念与 OpenSpec proposal / spec / tasks 有重叠，需要避免重复事实源。
