# 方案

> 当前方案沉淀区。优先阅读 `issues/` 与正式文档 `docs/`;`archive/` 只保留历史方案,不作为当前依据。

## 当前入口

- `issues/`:真实使用中发现的问题、决策、实施和收口记录。
- `roadmap.md`:有意 deferred 的后续迭代项(当前不做、重要、后续迭代)。
- `../docs/`:当前对外方法论文档。
- `../handoff.md`:当前态最新快照。

## 归档

- `archive/`:历史方案和阶段性整理稿。内容可能包含已废弃的 slash command、`config/ae-rules.md`、旧目录规划等信息,仅用于追溯,不要作为实现依据。
