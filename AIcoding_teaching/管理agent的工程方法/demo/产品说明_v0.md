# Knode v0 · 产品说明（讲师参照 · 现场对齐的「标准答案」）

> 这是 **讲师手里的标准答案**：用来判断现场「对齐」环节 agent 有没有问到点子上、范围有没有砍干净。
> **不要一上来甩给 agent**——让它在 A1 对齐时自己问出来，才是这一章要演的东西。

## 定位（一句话）

**Knode v0 = 一个最小可用的「skills hub」**：把团队踩过坑的**可复用节点（skill）**聚到一起，能从本地同步、能逛广场、能搜索看详情、能「下载」。

> 它就是第四章 Knode 的雏形——现场把它跑出来，第四章再讲它能长成什么、为什么是门生意。

## 形态（**纯前端 + 只读轻量服务**，为现场稳定性而定）

- **前端**：一个 `index.html`，零构建静态页。
- **轻量服务**：① 同步脚本 `sync`（扫 `.claude/skills/` 读 frontmatter → `skills.json`）；② 静态服务器（`python -m http.server`，只为让页面能 fetch json）。
- **全程只读**：不写盘、不建库、无自写后端 API。现场没有会崩的长运行服务；真崩了直接开 HTML 兜底。

## 数据源（两个）

1. **本地**：同步脚本扫 `.claude/skills/`（`ae setup` 刚装好的），用正则读每个 skill 的 frontmatter（`name` / `description`）→ 生成 `skills.json`，标 `scope: 本地`。**零依赖、不解析完整 YAML**。
2. **广场**：`plaza_nodes.json`（4 张共享节点，含 `scope: 团队 / 集团`），模拟团队/集团共享池。

## 节点卡片字段

| 字段 | 含义 | 必填 |
|------|------|------|
| `id` | 唯一标识（kebab-case） | ✅ |
| `name` | 人读名称 | ✅ |
| `scope` | 来源：本地 / 团队 / 集团 | ✅ |
| `when` | 触发场景（什么时候该用它） | ✅ |
| `input` / `output` | 输入 / 输出契约 | — |
| `pitfalls` | 踩坑提示（最贵的部分，也用于安全徽章） | — |
| `tags` | 标签，用于搜索 | — |
| `owner` / `updated_at` | 谁维护 / 更新时间 | — |

## v0 范围（做什么 / 不做什么）

**v0 做**（纯前端能稳跑）：

1. **我的节点**：同步脚本把 `.claude/skills/` 扫成卡片。
2. **广场**：用一个「来源」过滤器（本地 / 团队 / 集团）统一呈现，**不做三个独立页面**。
3. **搜索 + 标签过滤 + 详情**：关键词命中 `name` / `when` / `tags`。
4. **下载（轻量版）**：把节点「加入我的清单 / 复制 `ae` 安装命令」，**不真写盘**。
5. **安全徽章（轻量版）**：纯前端 lint——卡片文本含「凭据 / 密钥 / shell / 写盘 / 删除 / 驱动后台」等关键词 → 标「需注意」，否则「常规」。

**v0 不做**（现场明确砍掉——这是对齐的高光）：

- **上传 / 投稿到广场**：要写回共享池 → 需要真后端 → 后续。
- **真安装到本地 skills 目录**：写盘 → 后续，先用「复制安装命令」替代。
- **深度安全扫描**：v0 只做关键词徽章 → 后续接真规则。
- **登录 / 权限 / 多人 / 编辑 / 删除** → 后续。

## 校验规则（TDD 要断言的，**全是纯函数**）

- 同步解析：一段 frontmatter → 节点；缺 `name`/`description` 的目录跳过；按 `id` 去重。
- 搜索过滤：关键词命中 `name` / `when` / `tags`（搜 `email` → 命中 `powerautomate` 卡）。
- 安全徽章：`pitfalls` 含「凭据 / shell / 写 / 驱动」→ 返回「需注意」（如 `api-fetch-attachment`、`drive-backend-batch-add`）。

## 验收标准（A6 当场演示）

1. 起静态服务器，页面列出 **本地同步的若干张** + **广场 4 张** 卡片。
2. 搜索框输入 `email` → 命中邮件抓取卡。
3. 「来源」切到 `集团` → 只剩 `scope=集团` 的卡。
4. 点一张卡「下载」→ 进入「我的清单」/ 弹出 `ae` 安装命令（不写盘）。
5. `api-fetch-attachment` / `drive-backend-batch-add` 显示「需注意」徽章。

现场结果命中这几条，就证明「管理 agent」这套方法把一个模糊的**产品**需求做对了。
