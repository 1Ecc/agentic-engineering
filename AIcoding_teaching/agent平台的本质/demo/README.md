# 第一主题 · 演示手册：agent / 龙虾的本质

一套**可现场跑、一步步演进**的 demo。从「单轮对话的小脚本」长成「网页版小龙虾」，
让混合人群（研发 / 业务 / 产品管理）亲眼看到 agent 不神秘。

> 一句话主线：**agent = 大模型 + 一个循环 + 执行命令 + 一份说明书（提示词 / 技能）**

---

## 准备（讲师在课前做好）

```bash
cd AIcoding_teaching/coding本质/demo
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # 填好 BASE_URL / API_KEY / MODEL，推荐 OpenRouter
source .env
```

建议另开一个**空目录**当 agent 的工作区跑 step4–6（见下方风险提示）。

---

## 演进路线（每步只比上一步多几行 —— 这就是「现场演进」的爽点）

| 步骤 | 文件 | 现场演示 | 给非技术人的「那句话」 |
|---|---|---|---|
| 1 单轮 | `step1_single.py` | 跑出「你好」的回复 | 模型就是个「问→答」的函数，没记忆、不动手 |
| 2 多轮·无记忆 | `step2_multi_nomem.py` | 你好 → 1+1 → 再加1（**翻车**） | 模型本身没有任何记忆 |
| 3 多轮·有记忆 | `step3_multi_mem.py` | 同样追问（**这次对**）+「刚刚说了啥」 | 记忆=把历史再喂一遍；看着已像网页聊天 |
| 4 第一个 agent | `step4_agent.py` + `AGENTS.md` | 「创建 hello.txt 写 hello world」 | 加一份说明书 + 一个循环，agent 就诞生了 |
| 5 装技能 | `step5_agent_skill.py` + `skill.md` | 「北京现在天气？」**先翻车**→装 skill 后查到实时天气 | 厉害的是命令+模型知道用啥命令+你给的说明书 |
| 6 换皮 | `step6_web/` | 网页/手机远程操作小龙虾 | 大众认知的龙虾≈内核+一层皮，能否干活看内核 |

运行方式：`python step1_single.py`…依次类推；第 6 步：

```bash
cd AIcoding_teaching/coding本质/demo/step6_web
source ../.env
../.venv/bin/python server.py
```

启动后终端会打印两个地址：
- 电脑访问：`http://127.0.0.1:5000`
- 手机访问：形如 `http://<电脑局域网 IP>:5000`，手机和电脑需要在同一 Wi-Fi

想在电脑上同步看到手机端操作过程时，电脑浏览器也打开上面的电脑访问地址即可。step6 会把任务、
Agent 思考、执行命令、本机反馈和完成结果写到服务端事件流里；手机发出的任务会同步显示在电脑页面。
启动服务的终端也会打印同一套关键过程，适合现场投屏兜底。

如果 `5000` 被占用，可临时换端口：

```bash
LOBSTER_PORT=5056 ../.venv/bin/python server.py
```

step6 默认在 `step6_web/` 目录执行模型返回的命令；如需换隔离工作区，可设置 `LOBSTER_WORKDIR=/path/to/sandbox`。

---

## 三个反复敲打的「本质」

1. **agent 就是个无聊的循环**——判断 → 执行命令 → 把结果喂回 → 再判断。
2. **万物皆可命令 = 万物皆可 coding**——读文件、起服务、调远程 API 都是一行命令；
   回扣本次培训主题 **AI coding**。
3. **不是它厉害，是你厉害**——同一只龙虾，装了 skill 才脱胎换骨。对业务/产品最有共鸣。

---

## 收尾：用「痛点」引出下一主题

演进过程中会自然暴露问题，正好当钩子，不要停在「20 行很酷」：

- step3 的 `messages` 越滚越长 → **上下文 / 记忆管理**
- step5 的 skill 越来越多、命令谁来管 → **技能复用与组织**
- step4/6 直接跑模型给的 shell → **稳定性、权限、安全**

> 这些恰恰是 **codex / claude code 这类工程化框架**要解决的 ——
> 于是顺势进入第二主题：为什么要用成熟平台，而不是自己手搓 20 行。

并补一刀**风险**（提示词注入 / 对齐）：在 `AGENTS.md` 里塞一句恶意指令，
agent 就会照做——它根本不理解命令的含义，所谓「智能/情绪」都是提示词引导的。

## ⚠️ 风险提示（务必先讲、先设防）

step4–6 会**真实执行**大模型返回的 shell 命令。请：
- 在隔离 / 测试目录或容器里运行，别在生产机或重要目录跑；
- 现场最好用「列目录、建文件、下载到本目录」这类无害任务演示；
- 这本身就是最好的安全教学素材——把它讲成第 6 步的风险落点。
