# 第二章 · 为什么需要工程化平台

> 1 小时培训第二章（约 15 分钟）。承接第一章「agent = 模型 + 循环 + 命令 + 说明书」，落到 **claude code / codex 这类 AI IDE 上**。

## 这一章要讲什么

核心问题：**既然 20 行就能写个 agent，为什么还要用 claude code / codex？**

一句主张（沿用第一章收尾）：

> agent 本体很简单，难且值钱的是它外面那层「壳」(harness)；平台的价值就是把这层壳做成了成熟工程。

脊柱：第一章亲手暴露的三个痛点（越喂越贵、越跑越危险、越复杂越不稳）→ 平台正好用三块能力补上（上下文管理 / 工具生态 / 权限安全）→ 这就是 harness engineering。最后落到**快速上手**：Claude Code / Codex；没订阅用 **cc switch** 接国产模型（写代码偏 **GLM-5.2**、要知识偏 **DeepSeek V4 Pro**）。

## 呈现形式

讲稿给「话术 + 顺序」，**功能本身现场在 claude code / codex 里实操演示**（不靠截图堆砌）。
